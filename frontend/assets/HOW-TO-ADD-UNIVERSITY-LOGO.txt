HOW TO ADD THE UNIVERSITY SEAL — CoughPH
===========================================

The header on every page now has a small logo slot next to the
"CoughPH" name. Until a real image is added, it just stays hidden —
nothing breaks, the header looks exactly as it did before.

STEP 1 — Pick your image
---------------------------
- A square version of the University of Rizal System seal/logo
  works best (e.g. 200x200px, transparent PNG background looks
  cleanest against the white header).
- Keep the file small (under ~100KB) since it loads on every page.

STEP 2 — Name and place the file
------------------------------------
Save it into the assets folder using exactly this filename:

    coughph/
    └── assets/
        └── university-seal.png   <-- put it here

STEP 3 — Refresh
-------------------
Reload any page. The logo should appear automatically next to
"CoughPH" in the header — no code changes needed if you used the
exact filename above.

USING A DIFFERENT FILENAME
------------------------------
If you'd rather use your own filename, open each HTML file and find
this line near the top of <body>:

    <img class="brand-logo" src="assets/university-seal.png" ...>

Change "assets/university-seal.png" to match your actual file. This
line appears once per page (9 pages total), so you'd need to update
it in each file if you go this route — easiest to just use the exact
filename above instead.

ADJUSTING THE LOGO SIZE
----------------------------
In css/style.css, search for ".brand-logo":

    height: 30px;
    width: 30px;

Adjust both values together to keep it square.
