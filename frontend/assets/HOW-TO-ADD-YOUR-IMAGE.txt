HOW TO ADD YOUR OWN HERO IMAGE — CoughPH
==========================================

Right now the homepage hero shows a dashed placeholder box that says
"Your image goes here." Follow these steps to replace it with your
own photo or graphic.

STEP 1 — Pick an image
-----------------------
- Landscape-ish photos work best (roughly 4:3, e.g. 1200x900px or
  1600x1200px). The box will crop to fit, so avoid images where
  important details sit right at the edges.
- Keep the file size reasonable (under ~500KB) so the page loads
  fast. If your file is a huge phone photo, resize/compress it first
  (any free tool like squoosh.app works fine).
- JPG or PNG both work.

STEP 2 — Name the file
------------------------
Rename your chosen image to exactly:

    hero-image.jpg

(If you'd rather keep your own filename, that's fine too — see
"Using a different filename" below.)

STEP 3 — Put it in the right folder
-------------------------------------
Copy the file into the "assets" folder, so the path looks like:

    coughph/
    ├── index.html
    ├── about.html
    ├── team.html
    ├── legal.html
    ├── screening.html
    ├── login.html
    ├── css/
    ├── js/
    └── assets/
        └── hero-image.jpg   <-- put it here

STEP 4 — Refresh the page
----------------------------
Open (or reload) index.html in your browser. The placeholder box
should be replaced automatically by your image — no code changes
needed if you used the exact filename above.

USING A DIFFERENT FILENAME
----------------------------
If you don't want to rename your file, open index.html in a text
editor, find this line near the top of the <body>:

    <img class="hero-image" src="assets/hero-image.jpg" ...>

and change "assets/hero-image.jpg" to match your actual filename,
e.g. "assets/my-photo.png".

ADJUSTING HOW THE IMAGE LOOKS
--------------------------------
All of this lives in css/style.css, under the comment
"Hero image slot" (search for .hero-image-wrap):

- Change the box's shape:
    aspect-ratio: 4 / 3;      → try 1 / 1 for a square, 16 / 9 for wide

- Change how muted/toned-down the image looks:
    filter: saturate(0.9) contrast(0.97);
    → increase saturate toward 1 for full color, decrease toward 0.7
      for a more washed-out, background-y feel

- Change which part of the image shows when it's cropped:
    add object-position: top; or object-position: 30% 50%;
    to the .hero-image rule

- Remove the rounded corners:
    change border-radius: 18px; to border-radius: 0;

That's it — the placeholder box disappears automatically the moment
a valid image loads at that path, so you can leave it as-is until
you're ready.
