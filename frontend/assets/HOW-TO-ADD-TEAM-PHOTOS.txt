HOW TO ADD TEAM &amp; FACULTY PHOTOS — CoughPH
==============================================

team.html now shows a rounded-square photo frame for each researcher
and each faculty member. Until a real photo is added, each frame
falls back to the person's initials on an accent-color background —
same idea as the homepage hero image placeholder.

STEP 1 — Pick your photos
---------------------------
- Roughly square, front-facing photos work best (e.g. 400x400px to
  800x800px). The frame will crop to fit, so keep faces centered.
- Keep each file under ~300KB so pages load fast.
- JPG or PNG both work.

STEP 2 — Name and place each file
------------------------------------
Researchers go in assets/team/, faculty go in assets/faculty/, using
exactly these filenames:

    coughph/
    └── assets/
        ├── team/
        │   ├── desiree-mejes.jpg
        │   ├── ahldous-argayoso.jpg
        │   ├── rhein-cama.jpg
        │   ├── michael-nepomuceno.jpg
        │   └── mark-pesuelo.jpg
        └── faculty/
            ├── fredelina-de-leon.jpg
            ├── paul-alfonso.jpg
            ├── allan-anorico.jpg
            ├── erickson-marcos.jpg
            └── norman-francisco.jpg

STEP 3 — Refresh the page
----------------------------
Open (or reload) team.html. Each placeholder swaps for the matching
photo automatically — no code changes needed if you used the exact
filenames above.

USING DIFFERENT FILENAMES
----------------------------
If you'd rather use your own filenames, open team.html in a text
editor. Each person has a line like:

    <img class="team-photo" src="assets/team/desiree-mejes.jpg" ...>

Change the src path to match your actual file, e.g.
"assets/team/desiree.png".

ADJUSTING HOW THE FRAME LOOKS
--------------------------------
All of this lives in css/style.css, under the comment
"Photo frame slot" (search for .team-photo-wrap):

- Change the frame size:
    width: 84px; height: 84px;   → make bigger/smaller as you like

- Change the corner roundness:
    border-radius: 16px;   → lower for sharper corners, or 50% for a
                              full circle

- Change how muted/toned-down the photo looks:
    filter: saturate(0.9) contrast(0.97);
    → increase saturate toward 1 for full color

That's it — the initials fallback disappears automatically the
moment a valid photo loads at that path, so you can add photos one
person at a time whenever you have them.
